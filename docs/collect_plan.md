# 采集与录入计划（2022–2026）

## 1. 采集维度

- 地区：北京、上海、江苏、浙江、广东
- 年份：2022、2023、2024、2025、2026
- 考试：高考、一模、二模、三模、四模、模拟
- 专题：导数、立体几何

## 2. 录入优先级（建议）

1. 高考真题（五地五年）
2. 一模、二模
3. 三模、四模、模拟

## 3. 质检规则

- 必须有来源（年份+地区+考试名+题号）
- 同题去重（题干相似度+答案一致）
- 标注题型与知识点
- 解析可后补，但答案必须先完整

## 4. 文件维护规则

- 每个文件只放一个地区+年份+考试类型
- 同步维护 `.md` 与 `.html`
- 文件命名统一：`{exam_type}.{md|html}`
